Creator Guide

Everything you need to run Dante for Creators on Mac, iPhone, and iPad.

Creator Script Library & Read-Time Estimator

Create, pin, search, duplicate, and organize multi-page scripts directly in the sidebar on Mac or the Script Library sheet on iPhone and iPad. Dante counts spoken words (automatically ignoring [stage cues]) and calculates estimated read duration at your chosen speaking pace (90–240 WPM).

Creator Format Presets

  • YouTube Studio (150 WPM): Word Tracking, near-camera framing, large legible text, screen awake.
  • Shorts / Reels / TikTok (165 WPM): 60-second duration indicator, bright stage cues, Record mode ready on iOS.
  • Podcast / Interview (140 WPM): Ad-lib resilient Smart Follow, paragraph dividers, elapsed timer, hidden from screen share.
  • Keynote / Live Stream (135 WPM): Pinned below the MacBook notch, auto next page, screen awake, hidden from screen share.

Smart Follow & Local AI Models (macOS)

In Settings → Guidance, pick Apple Speech for instant setup or Local Model on Apple Silicon Macs for 100% offline transcription. Recommended models include Nemotron 3.5 ASR Streaming 0.6B (live streaming), Qwen3-ASR 1.7B (strong accents & 30 languages), and Canary 180M Flash (lowest memory).

Files, PowerPoint Import & Automation (macOS)

  • Save and share standalone scripts as .dante files via File → Save As….
  • Drop any .pptx deck onto the editor to extract slide presenter notes into pages.
  • Launch directly from automation tools using dante://read?text=Hello%20Creators or macOS Services (Read in Dante for Creators).

Remote Connection & Director Mode

Enable Remote (default port 7373) to mirror your prompter to an iPad, phone, or TV browser on the same Wi-Fi network, or enable Director (default port 7575) so a producer can push and live-edit scripts in real time.
